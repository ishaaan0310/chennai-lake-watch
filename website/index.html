Chennai Lake Watch

The water in Chennai's lakes, measured from space. Every few days a satellite passes over the city; this pipeline finds the new images, measures how much of each lake is water, and tracks it over time: monsoon filling, summer shrinkage, and floods.

How it works

A fully serverless pipeline on AWS, defined as infrastructure as code and running within the free plan.

Schedule

EventBridge Scheduler starts the workflow every morning at 9:00 IST.

EventBridge SchedulerStep Functions

Find scenes

Earth Search, a STAC catalog of the AWS Open Data Registry, returns new Sentinel-2 images over each lake.

AWS Open DataSTAC

Measure water

Lambda reads only the lake's pixels from Cloud-Optimized GeoTIFFs, masks clouds, and computes the water index (NDWI).

LambdarasterioNumPy

Store and alert

Results go to DynamoDB, water maps to S3, and SNS emails when a lake changes sharply.

DynamoDBS3SNSCloudFront
Contains modified Copernicus Sentinel data, accessed via the AWS Registry of Open Data and Element 84 Earth Search. Water areas are estimates from 10 m pixels and can be affected by haze, floating vegetation and the lake outlines used.
